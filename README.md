# VK-бот «Список покупок»

Мини‑проект чат‑бота для ВКонтакте, который помогает пользователю вести список покупок: добавлять товары, отмечать как купленные, получать список и очищать его.

## Функционал

- Добавление товара в список покупок
- Переключение статуса «куплено/не куплено»
- Отправка текущего списка пользователю
- Очистка списка
- Автоматическое создание базы данных при первом запуске

## Стек технологий

- Python 3.10+
- Peewee (ORM)
- VK API
- python-dotenv
- SQLite
